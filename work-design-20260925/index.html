01先建立工作原則

先問這件事如何帶來結果，再決定要不要占用他的時間。

1

需要帶來產值

能推進近期商機、完成已接訂單，或在必要期限內守住交付。成果要能核對，不能只用「有在忙」。

2

不立即需要，不做

沒有近期收益路徑、也沒有必要期限，先不啟動。不先全面改版、買設備、開更多帳號或整理所有歷史資料。

3

必要工作，限期完成

文書、產權資料、當期歸檔等不一定立即成交，但需要具體截止日、準備時間及覆核人，不是等有空。

P0 即時風險安全／服務中斷／不可延誤的節點。
P1 近期產值有需求、有訂單、有明確下一步。
P2 必要限期預留工時，期限前完成與覆核。
P3 暫不啟動無收益路徑或啟動條件尚未具體化。

產值分開記：訂單、收款、成本分開核對；詢問、預約、刊登是前導成果，不是收入。直選家沿用免費定位時，要另行核准平台成長投入；VELO 需確認真實場次與商業目的。同一筆商機不可跨品牌重複計算。

02逐項核對：怎麼交才合理？

保留原來的 13 項主要工作與 3 項次要工作，改用「承接方式」討論，不用人格標籤判斷成敗。

本期重點 0 / 3

適配度，不等於執行優先級

活動協調可能適合他，但沒有實際場次就不急著做。文書未必適合作為主軸，但必要期限仍然有效。

不喜歡，不等於不用做

先分清楚：是不會做、規格不明、容量不足，還是長期不願完成？提供工具與訓練後，再看實際結果。

沒有符合的工作，請換一個關鍵字。

上面的標記全部是建議。「本期重點」最多選 3 件；已接服務與到期必要工作仍須另外預留工時，不因未勾選而取消。勾選、決議與日期只儲存在本機，不會修改 Notion，也不會替你派工。

03工作方向：給範圍，不給一籃子雜事

角色設計提案：讓他對一段完整結果負責，同時保留最低限度的例行責任。

一個主專案 ＋ 一條固定營運線

先選一個有近期目的的內容／開發／活動專案，再搭配赫頌既有派工。不要一開始就要求所有品牌全面運作；現有交付與到期工作先排容量。

方法給自主，成果與界線固定

每張任務說清楚：為誰、做出什麼、何時完成、能花多少、誰驗收、何時升級。讓他選方法，但不能自行改價、付款、退款或增加專案。

完成包含收尾，不只包含熱鬧的前半段

辦活動包含確認與結案；拍影片包含交件與核准；開發包含下一步與追蹤日。不能把不喜歡的收尾永遠丟回你們身上。

把重複工作變成有終點的小批次

廣告集中上傳；文書按一案一清單；照片按當期案件管理。先由資料產生者按標準上傳，再追缺漏，不讓一個人替所有人重新整理。

保護拍攝與剪輯時間，緊急事項有備援

把集中產出時段與派工回覆時段分開。真急件由備援接手或重排；每次插單要說明哪件原工作延後，不要求同時救火又深度剪片。

夫妻統一排程，避免雙頭指揮

兩人都能提需求，但指定一位最終排程人；每件工作只有一位最終驗收人。等待主管批准或補素材，也要被記成卡點，不直接算成員工延誤。

「能發揮」和「要負責」必須一起成立。

建議起始容量示例：50% 主專案、25% 固定營運、15% 必要行政、10% 緩衝。這不是實測配比；先扣已接訂單與真實期限，再依實際工時調整。若必要工作已占滿容量，就縮小內容範圍，不把兩份工硬塞成一份。

主專案 50%營運 25%行政 15%10%
同一素材，不代表所有品牌都要貼：以主理人為 IP，可拍不動產、悟饕團訂或直選家找房需求等題材。每次先選一個目的，一次拍攝後產出主影片與相關短文，發到適合的帳號。悟饕題材要連到真實可接的團訂詢問；不額外增加未核准工作。

04用兩週小範圍試行，不用猜人格

以下是管理觀察窗口，不是法律上的試用期，也不是保證兩週成交。

第一步 / 對齊與試作

先分能力與偏好

確認可用工時、已有技能及要訓練的部分。用一份現有素材，試做短片與修稿；用一案示範文書核對。不熟悉的系統先教，不把首次操作慢當人格缺點。

第二步 / 真實小專案

交一段完整結果

選一個有需求的小專案，加一條固定營運線。核對企劃、協調、交付及收尾；設清楚範圍和檢查點，不用人為製造危機測試他。

第三步 / 重複一次再回顧

看第二輪，而非只看第一天

讓他在新鮮感下降後再做一次同類任務，觀察準時率、錯誤、修稿配合、追蹤完成及主管介入時間。證據足夠才擴量；不足就延長觀察或補訓練。

共用驗收：是否準時、首次交付是否正確、需要提醒幾次、能否完成修正與結案、推進哪些有效商機、實際用了多少工時。成交受多方影響，不把所有營收壓在新員工身上；也不只看他表現得多積極。

方法參考：以接近實際職務的工作樣本觀察表現。OPM 亦提醒，預計到職後才訓練的技能，不宜直接當作入職時就應具備的能力。此處是工作設計建議，不是標準化測驗。閱讀方法來源 ↗
